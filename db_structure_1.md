# СТРУКТУРА БД


## Таблица countries (CountryModel)
--- основная таблица с инфой про страны ---
id (str) - кодовое название страны (содержит только буквы и _). Является уникальным идентификатором
name (str) - нормальное название страны на русском
colorId (str) - дублирование цветового айдишника из JSONов с геометрией. Возможно оно в бд и вовсе ни к чему
parent (str/None) - айдишник страны, которая эта подчинена или в чей состав входит (если не подчинена, то None).
    Является внешним ключом
history (str) - список айдишников, которые формируют собой историю этой страны. 
    Формат: "old_finland,sweden_finland,rus_finland,finland" (значение из поля id в этом списке всегда присутствует)

parent_country (CountryModel/None) - сюда подтягивается связь по ключу parent
children (List[CountryModel]) - сюда подтягивается связь по ключу parent



## Таблица videos (VideoModel)
--- основная таблица с инфой про видео ---
num (int) - номер видео по времени выхода на канале. От 1 и до 300 с чем-то там. Является уникальным идентификатором
name (str) - название видео
link (str) - ссылка на само видео на ютубе
image_file (str) - название файла, где хранится картинка с превью видео
description (str) - краткое описание, что содержится видео
quality (str) - HEX-код цвета качества. Для самого первого видео это "#990000", 
    для большинства видео (всех начиная с какого-то конкретного, которое потом выберу) "#009900",
    для всех остальных это промежуточные значения между ними.
countries (str) - список стран (айдишников), с которыми видео связано. Формат: "rus_emp,ussr,russia"
chronology (str) - инфа о том, какие стран и времён касается видос. Формат - json-строка следующего вида:
    {
        "rus_emp": {
            "1812-1855": 1,
            "1880-1904": 1,
            "1905-1906": 2,
            "1907-1916": 1,
            "1917-1917": 2
        },
        "ussr": {
            "1917-1922": 2,
            "1923-1991": 1,
        },
        "russia": {
            "1991-2020": 1
        }
    }
    2 - основное, то есть видео сконцентрировано на этом
    1 - косвенно, то есть в видео эта тема упоминается мельком
    Года всегда расставлены по хронологии и в рамках одной страны (с одним айдишником) не накладываются



## Таблица years (YearModel)
--- вспопогательная таблица с инфой про года (дублирует инфу из предыдущих таблиц, но в ином виде для быстродействия) ---
year (int) - номер года. Является уникальным идентификатором
videos (str) - список видео, связанных с этим годом. Формат: "14,27,62,145,208,209,210,211,295"






# РАБОТА ЗАПРОСОВ


## Запрос /videos/1950?country=pakistan
--- Запрос всех видео, касающихся данной страны в данный год ---

1. Идём в таблицу videos и берём оттуда все видео, у которых в поле countries содержится страна с переданным айдишником
2. Идём в таблицу years и берём оттуда список видео для конкретного года
3. Находим пересечение и получаем предварительный список видео
4. Дальше проходим по всему списку видео. Для каждого лезем в поле chronology, находим страну с нужным айди.
    В полученном объекте ищем промежуток, внутрь которого входит этот год. Если значение 2, добавляем видео в список main, если 1 - в список indirectly, если отсутствует этот год - не добавляем

Результат выполнения запроса:
{
    "main": [ массив из VideoModel ],
    "indirectly": [ массив из VideoModel ]
}



## Запрос /videos/1950
--- Запрос всех видео, касающихся данного года ---

1. Идём в таблицу years и берём оттуда список номеров видео для конкретного года
2. Идём в таблицу videos и получаем список видео по списку номеров
3. Делаем обход всех видео: По очереди смотрим страны в chronology. Если находим промежуток, в который включён искомый год: 2, то сразу же добавляем в массив main и прекращаем обработку этого видео - идём к следующему. Если находим 1, то помечаем где-нибудь, но продолжаем обработку в попытке найти 2. Если так и не находим, добавляем в массив indirectly.

Результат выполнения запроса:
{
    "main": [ массив из VideoModel ],
    "indirectly": [ массив из VideoModel ]
}



## Запрос /videos?country=pakistan
--- Запрос всех видео, касающихся данной страны за всю её историю ---

1. Идём в таблицу countries, получаем по id страну, достаём поле history, получаем список айдишников стран
2. Идём в таблицу videos и берём оттуда все видео, у которых в поле countries содержится хотя бы одна страна из списка, получаем список видео
3. Делаем обход списка видео. В видео находим объекты всех нужных стран и объединяем этим объекты. То есть допустим если у нас есть {"res_emp": {"1914-1917": 2}} и есть {"ussr": {"1917-1922": 2}}, то они объединяются в {"1914-1922": 2}. Дальше анализируем объединённый объект. По очереди смотрим на каждый промежуток. Если в массиве main нет промежутков, пересекающихся с текущим, то просто добавляем его в массив main на соответствующую позицию, только вместо {"1914-1922": 2} ставим {"1914-1922": [<объект видео, который мы сейчас обрабатываем>]}. Если есть полностью совпадающий, то добавляем в соответствующий массив обрабатываемое сейчас видео. Если есть пересекающийся, например "1922-1936", то разбиваем на три, в данном случае 1914-1921, 1922-1922, 1923-1936 и соответствующим образом наполняем список видео

Результат выполнения запроса:
{
    "main": {
        "1900-1904": [ массив из VideoModel ],
        "1905-1905": [ массив из VideoModel ],
        "1906-1920": [ массив из VideoModel ]
    },
    "indirectly": { объект со структурой аналогичной объекту main }
}






# РЕАЛИЗАЦИЯ НА ФРОНТЕ

На фронте у нас всегда выбран какой-то год (не может быть не выбран).
Пользователь кликает на страну.
    Первым летит запрос /videos по году+стране. У него более короткая обработка и эта инфа будет отображена первым.
    Сразу же за ним летит запрос /videos только по стране.

В правой части экрана (на телефоне на весь экран) у пользователя открывается окошко, примерно на треть экрана. В нём сверху есть переключатели:
1. Верхний переключатель отвечает за страну. Если выбранное государство является дочерним, то слева название родительского государства, справа дочернего. Выбрано будет название дочернего, можно будет переключиться на родительское. После этого переключения, вид переключателей слегка меняется. Слева всё так же название родительского государства, а вкладка справа называется "регионы". Аналогично выглядит переключатель если изначально пользователь кликнул на родительское государство. Можно перейти на вкладку с регионами и выбрать конкретный, тогда переключатель примет вид описанный ранее. Аналогично меняются контуры выделенной на карте территории
2. Нижний переключатель отвечает за время. Слева номер выбранного сейчас года, справа "вся история". Изначально всегда выбран конкретный год. Там просто у нас есть 2 списка видео: сверху те что "основное", снизу те что "косвенно". Видео представлено названием и небольшой картинкой превью. По нажатии на видео уже в левой части экрана (на телефоне поверх предыдущего) тоже примерно на треть экрана открывается уже инфа о видео, где можно и перейти по ссылке на ютуб. При переключении на "вся история" тоже имеем два блока: сверху основное, снизу косвенно. Но это уже не просто списки. Это последовательность из небольших контейнеров, у которого слева небольшая область с указанием года (например 1918-1922 с переносом строки между ними), а справа большая область по списком видео, соответствующих этой временной области
